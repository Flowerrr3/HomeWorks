# homework1
1. Какой датасет выбрали и почему?
Выбрал датасет Rain in Australia, поскольку содержит большое число данных, а также удобно решать задачу классификации.
2. Список гипотез:
- Удаление значения NaN из целевой переменной 'RainTomorrow' не влияет на её распределение
- Заполнение NaN средним арифметическим соседей для числовых принаков не меняет распределения
- Модель DecisionTree лучше LogisticRegression
- Добавление кросс-валидации даст улучшение для DecisionTree по сравнению с LogisticRegression
- С помощью GreadSearch можно улучшить модели
3. Краткие результаты
- Гипотеза 1 подтверждена. Удалены все значения NaN, на соотношение Yes/No это не влияет
- Гипотеза 2 подтверждена. Заполнение NaN средним арифметическим не портит струтктуры данных, сохраняя их распределение
- Гипотеза 3 не верна, нелинейность дерева не даёт улучшения
- Гипотеза 4 не подтвердилась, из-за несбалансированности данных кросс-валидация не даёт улучшения
- Гипотеза 5 частично подтвердилась. Улучшение происходит только для LogisticRegression
